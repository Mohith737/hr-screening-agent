HR Screening Agent

AI-powered first-round candidate screening using Bolna Voice AI

Built by Mohith | Full Stack Engineer Intern

The Problem

  • Recruiters spend 15+ minutes per candidate on repetitive screening calls
  • 20 candidates per role = 5+ hours of low-value recruiter time
  • Manual screening is inconsistent, unscalable, and slow

The Solution

  • Voice AI agent that conducts structured screening calls autonomously
  • HR triggers call from dashboard agent calls candidate transcript returned automatically
  • Outcome: first-round screen time reduced from 15 min to zero

Tech Stack

  • Bolna Voice AI — conducts the call, returns transcript via webhook
  • React + Vite — HR dashboard frontend
  • Node.js + Express — API server and webhook receiver
  • Render — cloud deployment

Live Demo

  • Dashboard: https://hr-screening-client.onrender.com
  • GitHub: https://github.com/Mohith737/hr-screening-agent
  • Agent asks 5 structured questions
  • Browser testing available without phone credits
